# Original quote anchors for paper forecast prices

The regular crypto paper forecast path previously combined absolute targets based on the last closed candle with a current quote timestamp and signal price. A synthetic closed candle of100, target103 and current quote110 demonstrated the inconsistency: stored target represented a price below the current reference even though model return remained+3%. The research-only path already scales absolute prices to its reference while preserving model return.

The installed paper adapter now supplies a callback that binds each newly generated forecast to the already captured, authenticated pre-forecast quote. It scales spot, target and bands together, preserving model return, probability, model/version and all model abstentions. It does not fetch a later quote, change the model formula, lower entry thresholds, authorize execution or infer profit. Existing model, cost, identity, liquidity, exact forecast and risk gates still apply.

A distinct forecast ID binds original forecast ID, anchor version and authenticated quote ID/source identity/provider/price/timestamp. Original and anchored spot/target/bands, original and bound forecast IDs, model identity, expected return, probability and quote metadata persist in the existing signal JSON as forecast_reference. The forecast table retains its existing scalar schema and exact signal/forecast relationship. No migration or historical rewrite is included. Already-bound forecasts are rejected, including mutated objects with a reused quote ID; they are never reconstructed or rebound.

Both fast and deep scan paths bind before signal/forecast persistence and hand off only after required writes. Binding failures retain an explicit unavailable reason and no new forecast identity. Cash and unconfigured legacy paths are unchanged. Raw reference packets and stale or conflicting receipts cannot bind a forecast. The original candle and forecast objects remain unchanged.
